AI Transparency Notice helps website owners disclose when content has been created or assisted by artificial intelligence.

== Description ==

AI Transparency Notice adds a simple transparency notice to WordPress content.

Website owners can enable a notice, choose its position, customize the displayed text, and indicate whether content was created with significant AI assistance or only supported by AI tools.

This plugin is designed as an editorial transparency tool. It does not provide legal advice and requirements may vary depending on applicable regulations.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/ai-transparency-notice` directory.
2. Activate the plugin through the WordPress admin area.
3. Configure the settings from Settings > AI Transparency.

== Frequently Asked Questions ==

= Does this plugin detect AI-generated content automatically? =

No. The plugin allows editors to manually indicate AI usage and display a transparency notice.
