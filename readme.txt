== Description ==

Valentin Transparency Notice for AI Content adds a simple transparency notice to WordPress content.

Website owners can enable a notice, choose its position, customize the displayed text, and indicate whether content was created with significant AI assistance or only supported by AI tools.

The plugin is designed as an editorial transparency tool. It does not provide legal advice and requirements may vary depending on applicable regulations.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/valentin-transparency-notice-ai-content` directory.
2. Activate the plugin through the WordPress admin area.
3. Configure the settings from Settings > AI Content Transparency.
4. When editing a post, use the AI Content Transparency box to indicate the level of AI assistance.

== Frequently Asked Questions ==

= Does this plugin detect AI-generated content automatically? =

No. The plugin allows editors to manually indicate AI usage and display a transparency notice.

= Can I customize the notice text? =

Yes. The notice text can be customized from the plugin settings page.

= Can I display the notice with a shortcode? =

Yes. Use the `[valentin_ai_transparency]` shortcode in your content.
